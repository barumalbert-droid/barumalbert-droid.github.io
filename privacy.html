Privacy Policy

Last updated: November 1, 2026

Albert is a private personal assistant used by one family. Only the family members who set it up can use it.

What data Albert accesses

With each user's permission through Google sign-in, Albert can access that user's Gmail, Google Calendar, Google Tasks, Google Drive, Google Docs, Google Sheets and Google Contacts.

How the data is used

Albert uses this data only to carry out requests made by the family members themselves, for example summarizing emails, adding calendar events or finding a file. Albert does not take actions that change data without the account owner's approval.

Sharing

Data is never sold, never used for advertising, and never shared with anyone outside the family. It is processed on a private server controlled by the family, and by the AI model providers needed to answer requests.

Google API data

Albert's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Any user can revoke Albert's access at any time at myaccount.google.com/permissions.
